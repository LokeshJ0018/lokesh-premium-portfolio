PROJECT 02
GenAI & RAG

DocuMind AI

An AI-powered document question-answering application leveraging Retrieval-Augmented Generation (RAG) to deliver contextually grounded, accurate responses from complex PDF knowledge bases.

Core Implementation Highlights:

  • ✦ PDF Processing Pipeline: Text extraction, semantic chunking, and metadata parsing from multi-page documents.
  • ✦ Vector Embeddings in ChromaDB: High-dimensional vector indexing enabling rapid semantic similarity search.
  • ✦ Gemini API Synthesis: State-of-the-art language generation grounded strictly within retrieved document context.
  • ✦ Contextual Question Answering: Eliminates hallucinations by providing precise document-cited answers.
Python Gemini API ChromaDB PDF Processing RAG Architecture
Source on GitHub
PROJECT 03
IoT & Embedded Systems

IoT Smart Home Water Leak Detection

An IoT-based smart home solution designed to continuously detect water leakage using moisture sensors and instantly dispatch automated mobile alerts to prevent catastrophic structural damage.

Core Implementation Highlights:

  • ✦ Moisture Sensing Array: Continuous physical threshold monitoring across vulnerable smart home water points.
  • ✦ Automated Event Detection: Instantaneous algorithmic detection of anomalous liquid presence.
  • ✦ Real-Time Mobile Alerts: Immediate push notification dispatch to user smartphones for swift intervention.
  • ✦ Proactive Damage Prevention: Mitigates expensive property loss through low-latency hardware triggers.
IoT Sensors Moisture Detection Mobile Alerts Hardware Automation Embedded Logic
